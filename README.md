# CustomAgentCompetition
The idea of this project is to be able to teach a person how to use and prompt agents better so they can perform better in tasks in comparison to other existing models / agents

<img width="1534" height="771" alt="Screenshot from 2026-08-28 14-04-08" src="https://github.com/user-attachments/assets/90f1c874-e144-4764-9675-f03172971ae1" />

This has options to bring your own key (BYOK) and this tool is for local use only for you to practice prompting. You can compare this to other models like Qwen and OpenAI and others depending on configuration and current api keys you have.
There are many other options and models you can use since we allow you to edit the harness of each api call.
